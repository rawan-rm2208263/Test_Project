# Test Project - Milestone Task Manager

This project demonstrates a simple milestone-based task management system.

## Milestone Tasks

### Task 1: Small Task Inside The Milestone
A basic task implementation that handles simple operations.

### Task 2: Another Task For That Milestone  
An additional task that complements the first task with extended functionality.

## Features

- Task creation and management
- Milestone tracking
- Simple task completion workflow

## Usage

Run the tasks individually or as part of the milestone workflow.
